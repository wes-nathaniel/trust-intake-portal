## Suggested fix (not applied — READ-ONLY)
- **Third-party action:** In the Resend dashboard (https://resend.com/domains), add and verify the `igcfirm.com` domain (SPF/DKIM DNS records). Until verified, all outbound email from this From-domain will keep failing.
- Optional (Code/E1): if a different, already-verified sender domain exists, switch the From address to it; otherwise verification is mandatory.
- No secret is missing/empty (RESEND_API_KEY present). No redeploy needed for the diagnosis.
